# Quickback

说完一段，马上拿回反馈。用来练口语：英文说，卡住了就说中文。界面按原话分色显示，再给一版更地道的说法、几条可以补上的内容，以及一个追问。文字和录音都留在这台电脑上。

## 准备

1. 复制一份环境文件：

```powershell
Copy-Item .env.example .env
```

2. 用编辑器打开 `.env`，把 Google AI Studio 的免费 Key 填到 `GEMINI_API_KEY=` 后面。不要加引号，也不要把 Key 发给别人。

## 启动

在项目目录执行：

```powershell
.\run.ps1
```

浏览器打开 http://127.0.0.1:8765

改完 `.env` 要重启一次。服务只监听本机。

## 怎么用

- 点「开始说」，说完再点一次。先听一遍，满意再送出，不满意就重说。
- 英文和中文可以混在同一段里。中文会用底色标出来。
- 反馈分成三块：地道版只改卡住和别扭的地方。原版和地道版下面各有一句中文，用来对照意思；延伸另列，不写进地道版；追问接着同一套录音。
- 「记录」里可以回放以前的录音。
- 题目在页面的「题目」里增删改，每道题有创建和修改时间。练习页上也能改、删本题、追问，以及已经答过的每一段。每一段还能重答，送出后原版和地道版按新回答重写。刷新后还停在上次那道题。文件仍是 `questions.json`。已经练过的记录会留下原来的题目文字。

录音在 `data/sessions/`。每个练习一个文件夹，里面是 `session.json` 和每一轮的音频文件。整个 `data` 目录只留在本机，不会进 Git。

免费档的请求内容会被 Google 用来改进产品。
