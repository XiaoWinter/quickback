# Quickback

说完一段，马上拿回反馈。用来练口语：英文说，卡住了就说中文。界面按原话分色显示，再给一句意图、贴近原话的修正版、地道简单专业三种说法、几条可以补上的内容，以及一个追问。文字和录音都留在这台电脑上。

## 准备

1. 复制一份环境文件：

```powershell
Copy-Item .env.example .env
```

2. 用编辑器打开 `.env`。Gemini 的 Key 填到 `GEMINI_API_KEY=`，千问的 Key 填到 `DASHSCOPE_API_KEY=`。不要加引号，也不要把 Key 发给别人。页面右上角可以切换当前模型。千问朗读默认用 Serena，可在 `QWEN_TTS_VOICE` 里改。

## 启动

在项目目录执行：

```powershell
.\run.ps1
```

本机浏览器打开 http://127.0.0.1:8765 。同一局域网的设备用这台电脑的局域网地址，端口同样是 8765。已经签发证书时，服务改用 https；再用 http 打开同一个地址，会转到 https。

改完 `.env` 要重启一次。服务监听所有网卡。只想给本机用时，把 `.env` 里的 `QUICKBACK_HOST` 写成 `127.0.0.1`。

## 固定局域网地址

手机打开的地址要固定，否则证书对不上。不要沿用路由器临时分来的地址，改用同一网段里一个空闲地址。

1. 在 PowerShell 里运行 `ipconfig`，看「以太网」的默认网关和子网前缀。网关一般是路由器，前缀常见是 `24`。
2. 在这个网段里选一个空闲地址。例如网关是 `192.168.1.1`、前缀是 `24`，就在 `192.168.1.2` 到 `192.168.1.254` 里挑。先在路由器的已连接设备里看过，再 `ping` 一次，没有回应才算空着。最好选在路由器 DHCP 范围之外。
3. 打开「设置 → 网络和 Internet → 以太网」，在「IP 设置」里把「IP 分配」改成「手动」，打开 IPv4：

| 项目 | 填什么 |
| --- | --- |
| IP 地址 | 上一步选的空闲地址 |
| 子网前缀长度 | `ipconfig` 里现在的前缀 |
| 网关 | `ipconfig` 里现在的默认网关 |
| 首选 DNS | 和网关相同 |

4. 保存。再到路由器里把这个空闲地址留给这台电脑，避免以后分给别的设备。
5. 运行一次 `.\issue-cert.ps1`，让证书写上这个新地址，然后重新 `.\run.ps1`。手机改用脚本打印出来的 `https://` 地址。

## 手机证书

iPhone 只有在 https 下才能使用麦克风。在项目目录签发一次：

```powershell
powershell -ExecutionPolicy Bypass -File .\issue-cert.ps1
```

证书写在 `certs/`，不进 Git。私钥留在这台电脑，不要传到手机。签好后重新运行 `.\run.ps1`，用脚本打印出来的 `https://` 地址打开。

在 iPhone 的 Safari 里打开页面，点底部的「下载手机证书」。然后：

1. 打开「设置」。名字下面如果有「已下载描述文件」，点进去再点「安装」。没有的话，走「设置 → 通用 → VPN 与设备管理 → 已下载的描述文件」。
2. 打开「设置 → 通用 → 关于本机 → 证书信任设置」，打开 Quickback Local CA 的完全信任。

只用浏览器里的「继续访问」不够，麦克风仍然不可用。不要用 Safari 以外的浏览器下载，否则设置里不会出现描述文件。

根证书和服务器证书各 825 天。过期或这台电脑的局域网地址变了，再运行一次 `.\issue-cert.ps1`。根证书还在时，手机不用重新安装。

## 怎么用

- 点「开始说」，说完再点一次。先听一遍，满意再送出，不满意就重说。最长 3 分钟。
- 英文和中文可以混在同一段里。中文会用底色标出来。
- 反馈先给一句意图，说明这句话想说什么。修正版只改卡住和别扭的地方，贴近原话。原版和修正版下面各有一句中文，用来对照意思。多样表达把同一句再说成地道、简单、专业三档，事实和顺序不变。可以补上的说法另列，不写进修正版。追问接着同一套录音。
- 修正版和三档表达里，能抽出的功能性句组会单独列出。点短语听这句里切出来的发音。跟读录在本机；录过的可以重录或删除。
- 多样表达下面可以整理核心语块。每条有用法，并按这个情境造三句。说完会看语法和用得对不对。语块可以自己添加或删除。
- 「记录」里可以回放以前的录音。
- 题目在页面的「题目」里增删改，每道题有创建和修改时间。点问题本身进入这道题。标题旁是「进展」「进展统计」「删除」。练习页上也能改、删本题、追问，以及已经答过的每一段。每一段还能重答，送出后原版和修正版按新回答重写。已经归档的练习，在练习页的本题上可以继续回答。刷新后还停在上次那道题。文件仍是 `questions.json`。已经练过的记录会留下原来的题目文字。
- 「进展」按练习里已经答过的每一段出题，顺序一致。练习最下面还没答的追问不出现，也不另外出题，不加奖励分。先听再送出。每题从可理解性、切题、流利度打分，并列出具体纠错。答过的题旁边可以重答。答题前可以写几条草稿，不参与评分；答完后这些草稿留在这道题下面。点「结束这次」记入统计并打开「进展统计」，里面用 Chart.js 柱状图看原始分和平均每题。原始分是各题分数加总。「放弃这次」不记分。进展不写进练习记录。

录音在 `data/sessions/`。每个练习一个文件夹，里面是 `session.json` 和每一轮的音频文件。进展在 `data/progress/`。整个 `data` 目录只留在本机，不会进 Git。

免费档的请求内容会被 Google 用来改进产品。
